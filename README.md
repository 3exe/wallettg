# Auto Wallets (WalletTg)

Локальный веб-интерфейс для пакетной работы с кошельками Telegram WalletTg:

1. создаёт нужное количество кошельков в одном из форматов:
   - **Gram Wallet, 12 + 12 слов** — импортируется в Gram Wallet и MyTonWallet: первые 12 слов задают адрес, вторые 12 подписывают;
   - **TON, 24 слова** — стандартная TON-фраза (старый формат);
2. рассылает на каждый указанную сумму с основного кошелька (WalletTg, W5 или V4) пачками до 255 получателей в одной транзакции. Каждое пополнение несёт StateInit и само разворачивает кошелёк, а для формата 12+12 ещё и переключает его на ключ из вторых 12 слов. Отдельной транзакции развёртывания нет;
3. по желанию возвращает остаток на основной кошелёк: `баланс − комиссия − 0.001 TON`. Комиссия считается эмуляцией той же транзакции в локальной копии блокчейна.

Фразы новых кошельков показываются в таблице и скачиваются файлом `.txt`. Больше они нигде не сохраняются.

## Установка

Нужен Node.js 20 или новее.

```
git clone https://github.com/3exe/wallettg
cd wallettg
npm install
npm start
```

Браузер откроется сам. Если нет, открой ссылку из консоли: в ней ключ доступа, без которого сервер не отдаёт ни страницу, ни API. Ключ меняется при каждом запуске.

Токен toncenter (API-ключ) необязателен, но с ним запросы идут быстрее и кошельки обрабатываются по 4 параллельно. Бесплатный ключ выдаёт бот @tonapibot в Telegram.

## Запуск на VPS через SSH-туннель

Сервер слушает только `127.0.0.1`, поэтому снаружи он недоступен. Подключайся к нему через SSH.

На VPS:

```
tmux new -s aw
PORT=8787 npm start
```

Скопируй ссылку из консоли и отсоединись от tmux (Ctrl+B, затем D).

На своём компьютере:

```
ssh -N -L 8787:127.0.0.1:8787 user@your-vps
```

Пока команда работает, открой скопированную ссылку в браузере. С телефона то же самое делается в Termius (Port Forwarding: локальный порт 8787 → 127.0.0.1:8787).

Не открывай порт наружу: страница принимает сид-фразы.

## Безопасность

- Фразы обрабатываются только в процессе на машине, где запущена программа. В сеть (toncenter.com, при недоступности tonapi.io) уходят только подписанные транзакции.
- На VPS фразы проходят через его память; владелец сервера теоретически может их прочитать.
- Перед запуском интерфейс показывает адрес основного кошелька, сеть и итоговую сумму и ждёт подтверждения.
- Начни с 2–3 кошельков на маленькой сумме или с галочкой «Тестовая сеть».
